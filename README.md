# gitmemo

Google Drive上の `gitmemo` ファイルとリアルタイム同期する、ブラウザ完結型のマークダウンメモ帳です。

## 特徴
- **Google Drive 自動同期**: ログインするとDrive上の `gitmemo` ファイルを自動で読み込み・作成し、入力内容を自動保存します。
- **マークダウン対応**: リアルタイムプレビュー機能付き。
- **元に戻す / やり直し**: `Ctrl+Z` / `Ctrl+Y`（`Ctrl+Shift+Z`）およびツールバーからの履歴操作に対応。
- **サーバーレス・高セキュリティ**: サーバーを介さず、お使いのブラウザとGoogle Drive API間で直接通信します。

## プライバシーポリシー (Privacy Policy)

### 1. 取得する情報と権限（Google Drive API）
本アプリケーション（GitMemo）は、Google OAuth 2.0 認証および Google Drive API の `https://www.googleapis.com/auth/drive.file` スコープを使用します。
この権限により、**本アプリを通じて作成された `gitmemo` ファイル（またはユーザーが明示的に選択したファイル）のみ**にアクセスします。ユーザーのGoogleドライブ内にある他のファイルやフォルダを閲覧、変更、削除することは一切ありません。

### 2. データの保存先と第三者提供
本アプリはGitHub Pages上で動作する静的なWebアプリケーションであり、独自のバックエンドサーバーを持たない設計となっています。
- ユーザーが入力したテキストデータおよび認証トークンは、ユーザー自身のブラウザとGoogleのサーバー間の直接通信にのみ使用されます。
- 開発者や第三者のサーバーへユーザーデータや個人情報が送信、収集、保存、共有されることは一切ありません。
